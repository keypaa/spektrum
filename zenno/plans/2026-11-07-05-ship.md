# Phase 5 — Ship Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Spektrum as a host-agnostic production kit — a Prism import/export with a byte-exact round trip, a reference Docker deployment (web + worker + Caddy + Postgres + Redis + MinIO), backups, health/metrics/logging, security hardening, admin access, a load test, and a launch runbook — with no dependency on a specific cloud provider.

**Architecture:** The Next.js app stays the only user-facing surface; the existing BullMQ worker stays the only compile process. Import/export are server-side, pure-parse-then-persist: a security-validated pure parser turns a Prism archive into project drafts, and a DB writer persists them idempotently. The deployment kit is a single `docker compose` project that runs unchanged on any Docker host (VPS, VM, or a container platform); every host-specific value is an env var. Security is treated as a first-class input class: zip-slip, symlinks, zip bombs, oversize bodies, cross-origin, ownership, secret leakage, and upload sniffing all get explicit rejection paths and tests.

**Tech Stack:** Next.js 16.4.5 (App Router, Node runtime), React 19, TypeScript 6.0.3, Drizzle 0.45.4 + Postgres 16, Redis 7 + BullMQ, S3-compatible storage (MinIO), Better Auth 1.7.18, vitest 5, Playwright, `fflate` (zip), `prom-client` (metrics), `@sentry/nextjs` (optional error tracking), Caddy 2, Docker Compose.

**Spec:** `zenno/specs/2026-11-07-spektrum-design.md` — §13 (files, import, export), §10.5/§10.6 (auth/rate limits/hardening), §19 (API), §17 (open items). This plan adds the deployment and operations detail the spec defers to Phase 5.

## Global Constraints

- Node **26.13.0**, pnpm **12.18.0** (`.mise.toml`, `.node-version`, `package.json` engines + `packageManager`, `.npmrc engine-strict`); never a different version.
- TypeScript **6.0.3**, `strict`, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`; no `any` in exported signatures.
- Every mutating route: `requireUser()` → `assertSameOrigin(req, loadWebEnv().authUrl)` → `zod` parse → ownership → `errorResponse(e)`.
- `errorResponse` status contract (§10.5): `UnauthorizedError` 401, `ForbiddenError` 403 (429 when suspended), `CsrfError` 403, `ZodError` 400, `SyntaxError` 400, everything else 500 with a generic message.
- All copy verbatim from the spec; no emoji; icons are 16×16 `currentColor` registry SVGs; colors only from `tokens.css`.
- Host-agnostic: no cloud-specific SDK, CLI, or URL in application code. Every host value comes from env; the only host-specific artifacts are the reference compose/Caddy files.
- The real Prism export fixture is `e2e/fixtures/prism-projects-2026-11-05.zip` (copy of `/home/keypaa/Downloads/prism-projects-2026-11-05.zip`, 3 385 111 bytes, 16 projects). It is the round-trip oracle.
- Import size/entry limits default: `IMPORT_MAX_FILE_BYTES=26_214_400` (25 MiB), `IMPORT_MAX_TOTAL_BYTES=536_870_912` (512 MiB), `IMPORT_MAX_ENTRIES=50_000`, `IMPORT_MAX_RATIO=100`, `IMPORT_MAX_PROJECTS=200`.
- The document inline-content cap is **524 288** UTF-16 code units (the PATCH cap); larger text and all binaries go to the `uploads` bucket with `blobKey` and `content = null`.

## Review Focus

Security-critical inputs the plan must pin, each with the task that tests it:

1. **Zip-slip / traversal / absolute / backslash / control / over-long paths** in an archive → reject the entry, never write outside the project (Task 2). Also `.`/`..` segments and `..` after normalisation.
2. **Symlink entries** in the archive (unix mode `S_IFLNK`) → reject, never materialise a link (Task 2).
3. **Zip bomb / oversize / entry-count** → reject before decompressing, using central-directory `originalSize`, declared ratio and counts (Tasks 1–2).
4. **Oversize multipart body / file** on import → 413, not a 500 (Task 4).
5. **Cross-origin import/export** → 403 (`assertSameOrigin`), and **another owner's export** → 404, never 200 or 403 (Task 6).
6. **SVG/HTML-with-script** in the upload path → reject by magic bytes, never serve inline (Task 17).
7. **Secret leakage**: `SENTRY_DSN`, S3 keys, LLM keys, and the BYOK key never appear in metrics labels, logs, or error bodies (Tasks 15–17).
8. **SSRF / config**: `S3_ENDPOINT` and `LLM_BASE_URL` are operator-supplied; the app never fetches an archive URL (the upload is the body), and the metrics/health routes are not a proxy (Tasks 15, 17).
9. **Supply chain**: `fflate`, `prom-client`, `@sentry/nextjs` are pure-JS, pinned exactly; `pnpm audit --prod` is a CI gate (Task 17).

- [ ] **Step 3: Implement `readZip` / `writeZip` in `apps/web/src/lib/import/zip.ts`**

`readZip` uses `unzipSync(bytes, { filter })`: the filter receives `{ name, size, originalSize }`; throw `ZipError("too_large")` when `originalSize > maxFileBytes`, `ZipError("ratio")` when `originalSize / Math.max(1, size) > maxRatio`, and accumulate a running total to throw `too_large` when it exceeds `maxTotalBytes`; throw `ZipError("too_many")` when the entry count exceeds `maxEntries` (count in the filter; the central directory yields every entry). Map the result to `ZipEntry` with `mode` from the decoded external attributes (0 when absent). `writeZip` uses `zipSync` with `{ level: 6 }`.

- [ ] **Step 3: Implement `parsePrismArchive` in `apps/web/src/lib/import/prism.ts`**

Rules (spec §13.2):
1. Group entries by the first path segment (top-level directory); ignore stray root files.
2. For each entry, validate the path with the same rules as `normalizeDocumentPath` **plus** a symlink check: reject when `(mode & 0o170000) === 0o120000`; reject absolute, `..`/`.` segments, backslash, control chars, over 200 chars. Push the original path to `rejectedPaths` and skip.
3. Drop `preview/`. Keep `conversations/` separate.
4. Re-root `uploads/` and `prism-uploads/`: move their contents to the project root; if the target path collides, keep the directory prefix. For every `.tex` file, rewrite `includegraphics{uploads/<name>}` and `includegraphics{prism-uploads/<name>}` to `includegraphics{<name>}` and record `{from,to}`.
5. `main.tex` → `mainPath`; else promote the largest `.tex` containing `\documentclass` and set `promotedMain = true`; else `mainPath = null`.
6. Conversations: `items[]` → map each `message` item (`input_text` → user, `output_text` → assistant; join `content[].text`); `function_call*` / `apply_patch*` items → a `tool` turn with the item's `name`/`arguments`; `status:"unsupported"` → `{ skipped: true, reason }`. The thread title is the first user text truncated to 60 chars.
7. Classify `kind` by extension (`tex/bib/img/csv/other`) and set `text` to the UTF-8 decode for text kinds (tex, bib, csv, other that is valid UTF-8 and has no NUL byte) else `null`.
8. Cap projects at `limits.maxProjects ?? 200` (stop after the cap) and per-file bytes at `limits.maxFileBytes ?? 26_214_400`.
